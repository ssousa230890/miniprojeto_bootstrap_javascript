# Desafio da Semana — Bootstrap 5 e JavaScript

Mini-projeto desenvolvido para o desafio da semana do curso de Desenvolvimento Java, integrando **Bootstrap 5** (via CDN) e **JavaScript** (manipulação do DOM e `addEventListener`) para alterar o conteúdo e o estilo de um componente `Card` dinamicamente.

## Objetivo
- Praticar conceitos fundamentais do Bootstrap 5 (sistema de grade, abordagem *mobile-first*, classes utilitárias e componentes pré-construídos).
- Aplicar interatividade com JavaScript puro (`addEventListener` e manipulação de classes/texto no DOM).
- Organizar os projetos do curso no GitHub.

## Como executar
1. Baixe ou clone este repositório.
2. Abra o arquivo `index.html` em qualquer navegador moderno.
3. Clique no botão dentro do card para alternar entre o estado inicial e o estado atualizado.

## Estrutura do projeto
- `index.html` — Página com o componente `Card` do Bootstrap 5 e o script em JavaScript.
- `README.md` — Documentação do mini-projeto.
